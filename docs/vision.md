# Vision

## Product Concept

コーヒー体験を記録し、知識グラフとして育て、
自分の味覚やコーヒーの知識を自然に発見できるアプリ。

## Core Experience

Record → Connect → Discover

1. Record: 飲んだコーヒーを簡単に記録する
2. Connect: 産地・農園・品種・精製方法・焙煎・フレーバーがつながる
3. Discover: 自分の記録から、好みや未知の関係を発見する

## Why

コーヒーには、産地、農園、品種、精製方法、焙煎度、
抽出方法、フレーバーなど多くの要素があります。

しかし、一般的な記録アプリでは、各記録が時系列に並ぶだけで、
体験同士の関連や自分の味覚傾向を発見しにくいという課題があります。

このアプリは、コーヒーを単に保存する対象ではなく、
記録するほど理解が深まる個人知識ベースへ変えます。

## Target User

主対象:

- スペシャルティコーヒーに興味を持ち始めた人
- 自宅とカフェの両方でコーヒーを飲む人
- 詳しい専門知識はないが、自分の好みを知りたい人
- 記録を続けることで自然に学びたい人

## Product Identity

このアプリは次のものではありません。

- 豆を購入するECサイト
- 専門家向けの厳密なカッピング管理システム
- カフェ検索・口コミを主目的とするサービス
- AIチャットを中心としたサービス

このアプリは、自分のコーヒー体験から知識を育てる場所です。

## Success Definition

MVPの成功は、ユーザーが次の体験を完了できることです。

- コーヒーを記録できる
- 記録へ複数のコーヒー要素を関連付けられる
- グラフ上で記録と要素のつながりを確認できる
- 過去の記録や関連要素へ移動できる
- 「自分はこの産地やフレーバーをよく選んでいる」と気づける
